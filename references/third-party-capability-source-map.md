# Third-Party Capability Source Map

The repositories below were supplied as user-provided snapshots and used to identify useful measurement concepts. Their contents are not automatic truth and no third-party application source code is bundled in this Skill patch.

| Source | Snapshot role | Observed useful concept | Pixelkiez decision | Code reuse |
|---|---|---|---|---|
| Open Web Analytics | user-provided snapshot | first-party visitor/page/event analytics after instrumentation | optional future provider behind owner-analytics contract | none |
| Statping | user-provided snapshot | continuous availability and incident time series | optional future provider behind monitoring contract | none |
| CSP Auditor | user-provided snapshot | focused CSP configuration analysis | small independently implemented heuristic only | none |
| Web-Check | user-provided snapshot | broad public web/DNS/TLS/header probe patterns | selected concepts independently implemented in bounded gateway | none |

`reports/third-party-license-ledger.json` records snapshot digests, observed license evidence and reuse mode. Unknown or copyleft licensing is not resolved by copying code: this release avoids source reuse entirely.
